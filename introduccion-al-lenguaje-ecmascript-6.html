    Todos estos son documentos para principiantes. Los artículos siguen una secuencia lógica, pero están vagamente relacionados entre sí:

    • el documento [1] presenta el lenguaje PHP 7. Los lectores interesados únicamente en PHP y no en el JavaScript tratado en los siguientes artículos deberían detenerse aquí;
    • Los documentos [2–4] tienen como objetivo crear un cliente JavaScript para el servidor de cálculo de impuestos desarrollado en el documento [1];
    • Los marcos de trabajo de JavaScript [Vue.js] y [Nuxt.js] de los artículos 3 y 4 requieren conocimientos de las últimas versiones de ECMAScript, concretamente la versión 6. Por lo tanto, el documento [2] está destinado a quienes no estén familiarizados con esta versión de JavaScript. Hace referencia al servidor de cálculo de impuestos creado en el documento [1]. Por lo tanto, los lectores del [2] tendrán que volver a consultar el documento [1] en algunas ocasiones;
    • Una vez dominado ECMASCRIPT 6, podemos pasar al marco VUE.JS, que permite la creación de clientes JavaScript que se ejecutan en un navegador en modo SPA (aplicación de página única). Este es el documento [3]. Hace referencia tanto al servidor de cálculo de impuestos creado en el documento [1] como al código del cliente JavaScript independiente creado en [2]. Por lo tanto, los lectores de [3] tendrán que consultar en ocasiones los documentos [1] y [2];
    • Una vez que domines VUE.JS, podrás pasar al marco NUXT.JS, que te permite crear clientes JavaScript que se ejecutan en un navegador en modo SSR (renderizado del lado del servidor). Hace referencia al servidor de cálculo de impuestos creado en el documento [1], al código del cliente JavaScript independiente creado en [2] y a la aplicación [vue.js] desarrollada en el documento [3]. Por lo tanto, los lectores de [4] tendrán que consultar ocasionalmente los documentos [1], [2] y [3];

    La última versión del servidor de cálculo de impuestos desarrollado en el documento [1] puede mejorarse de diversas maneras:

    • La versión actual está centrada en el servidor. La tendencia actual (julio de 2019) se inclina hacia la arquitectura cliente-servidor:
      • el servidor funciona como un servicio JSON;
      • Una página estática o dinámica sirve como punto de entrada para la aplicación web. Esta página contiene HTML/CSS, así como JavaScript;
      • las demás páginas de la aplicación web se generan dinámicamente mediante JavaScript:
        • la página HTML puede generarse ensamblando fragmentos estáticos, proporcionados por el mismo servidor que sirve la página de inicio, o construirse íntegramente mediante JavaScript;
        • estas diferentes páginas muestran los datos solicitados al servicio JSON;

    De este modo, el trabajo se distribuye entre el cliente y el servidor. Al reducirse la carga del servidor, este puede atender a más usuarios.

    La arquitectura correspondiente a este modelo es la siguiente:

    JS: JavaScript

    El código JavaScript se ejecuta en el lado del cliente:

    • de un servicio que proporciona páginas o fragmentos estáticos o no estáticos;
    • un servicio JSON;

    Por lo tanto, el código JavaScript es un cliente JSON y, como tal, puede organizarse en capas [UI, lógica de negocio, DAO] (UI: interfaz de usuario), al igual que nuestros clientes JSON escritos en PHP. En última instancia, el navegador solo carga una única página: la página de inicio. El resto de páginas son recuperadas y renderizadas por JavaScript. Este tipo de aplicación se denomina SPA (aplicación de página única) o APU (aplicación de página única).

    Este tipo de aplicación también forma parte de lo que se conoce como aplicaciones AJAX: JavaScript asíncrono y XML

    • Asíncrono: porque las llamadas del cliente JavaScript al servidor JSON son asíncronas;
    • XML: porque XML era la tecnología utilizada antes de la llegada de JSON. Sin embargo, se ha conservado el acrónimo AJAX;

    Exploraremos esta arquitectura en los próximos capítulos. En el lado del cliente, utilizaremos el marco de trabajo de JavaScript [Vue.js] [https://vuejs.org/] para escribir el cliente JavaScript para el servidor PHP JSON que describimos en el documento [1].

    [Vue.js] es un marco de trabajo de JavaScript. Para entenderlo, debes dominar este lenguaje. En este documento, presentamos el estándar ECMAScript 6, que es la estandarización más reciente (a fecha de 2019) de este lenguaje. La historia y el papel de ECMAScript se pueden consultar en Wikipedia [https://fr.wikipedia.org/wiki/ECMAScript].

    Este documento proporciona una lista de scripts de consola de JavaScript en diversas áreas (estructuras del lenguaje, acceso a bases de datos, acceso a Internet, programación por capas y programación a través de interfaces). El documento concluye con dos aplicaciones:

    Una aplicación de consola que actuará como cliente para el servidor de cálculo de impuestos creado en el documento [1]. Este cliente tendrá la misma arquitectura que el cliente de consola PHP creado en el documento [1]:

    • las capas [7–9] serán las del cliente JavaScript que se ejecuta en una consola;
    • las capas [1–4] son las del servidor PHP 7 creado en el documento [1];
    • a diferencia del cliente de consola PHP creado en el documento [1], no habrá interacciones con el sistema de archivos local [6];

    Aquí tenemos una aplicación cliente/servidor en la que el cliente es una aplicación de consola. Se escribirá una segunda aplicación en la que el código de las capas [7–9] se portará a un navegador. Entonces estaremos listos para abordar los marcos de trabajo de JavaScript para navegadores de los documentos [3] y [4].

    Los scripts de este documento están comentados y se reproduce su salida en la consola. En ocasiones se proporcionan explicaciones adicionales. El documento requiere una lectura activa: para comprender un script, debes leer su código, los comentarios y los resultados de la ejecución.
